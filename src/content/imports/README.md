# MMS Hub source import — 15 September 2026

Source: https://www.hubmms-th.com/

53 captured records: 17 news, 6 events, 1 research item, 23 collaborator profiles,
5 team profiles and 1 About page. 159 image files are hosted under
`public/images/mms-hub`; source URLs are recorded per article in the JSON.

This is a source-language, repository-managed archive, not an automatic sync.
It does not create or overwrite database/admin collection entries. News is merged
into the public news feed; imported events/research appear in partner sections.
Team/collaborator profiles are explicitly MMS Hub profiles, not RISA committee appointments.
Original publication dates are preserved; these must not be assumed to be event dates.
Template/demo copy, unused theme graphics, admin-only drafts, credentials and
e-commerce boilerplate are excluded. Original-source links and roles remain intact.

Existing RISA database records take precedence over imported news with matching slugs.
To revise an imported record, edit the source JSON or explicitly migrate it into
the admin database; do not imply that the public import is currently admin-editable.
